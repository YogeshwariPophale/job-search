# Codex Prompt - Tailored Resume Builder

Use this when creating a job-specific resume.

## Rules

- Keep all claims truthful and grounded in `job_search_system/profile/candidate_profile.md`.
- Do not add unsupported tools or experience.
- Prefer one-page ATS format unless the user asks otherwise.
- Reorder and rewrite bullets to match the job's language.
- Preserve quantified impact: 40% manual reporting reduction, 200+ components, 85% validation cycle reduction.
- Add role-specific keywords only when they are supported by the candidate's real experience or coursework.

## Role-Specific Positioning

For data analyst / BI:

- Lead with SQL, Python, data quality, dashboards, KPI reporting, stakeholder communication.

For data science / ML:

- Lead with Python, statistics, anomaly detection, feature engineering, model evaluation, ML coursework, NLP/LLM project.

For manufacturing / operations analytics:

- Lead with Bajaj Auto, SAP datasets, AMR deployment, production planning, process optimization, root cause analysis.

For data engineering:

- Lead with SQL, PostgreSQL, Python pipelines, validation, Docker, Hadoop, PySpark.

## Deliverables

Create:

- Tailored resume PDF
- Tailored resume source file
- Cover letter or short application note if useful
- Screening answer draft
- Change summary showing what was tailored and why
