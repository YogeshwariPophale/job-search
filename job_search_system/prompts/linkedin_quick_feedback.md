# LinkedIn Quick Feedback Prompt

Use this for a fast, honest LinkedIn review.

```text
Give me LinkedIn Quick Feedback using my job_search_system.

Use:
- job_search_system/profile/candidate_profile.md
- job_search_system/profile/job_search_profile.md
- job_search_system/profile/preferences.yml
- job_search_system/templates/linkedin_profile_intake.md, if I pasted profile sections

LinkedIn input:
[paste LinkedIn URL or sections: headline, about, experience, skills, featured/activity]

Review these sections:
1. Photo/banner first impression, if visible or described
2. Headline
3. About section
4. Current and past experience descriptions
5. Skills and keywords
6. Featured section and recent activity, if provided

Output:
- What is working, with specific evidence
- What is hurting recruiter conversion
- Exact rewrite suggestions for weak sections
- Missing keywords for Yogeshwari's target roles
- Ranked action list:
  - Fix immediately
  - Fix this week
  - Nice to have

Tone:
- Direct and practical
- No generic encouragement
- No invented experience, metrics, tools, or certifications
```
