# Codex Prompt - Application Assistant

Use this when filling out an application.

## Safety

Stop for explicit user approval before:

- Submitting the application
- Sending a recruiter message
- Agreeing to legal terms
- Answering work authorization or sponsorship questions
- Entering salary expectations
- Uploading files if multiple file versions could be confused

## Form Filling Strategy

1. Use the tailored resume and cover letter for this company and role.
2. Copy exact contact details from `candidate_profile.md`.
3. Use `templates/screening_answers.md` as a base for screening responses.
4. Flag every unknown or sensitive field.
5. Summarize the completed form before submission.

## Final Review Checklist

- Company and role are correct.
- Correct tailored resume is uploaded.
- Cover letter is correct if required.
- Contact details are correct.
- Work authorization answers were confirmed.
- Salary answers were confirmed.
- No unsupported claim is present.
- User approved submission.
