# Notion Tracker Columns

If you want to mirror the guide in Notion, create a table called `Job Applications` with these columns:

| Column | Type | Options |
| --- | --- | --- |
| Company | Title | |
| Role | Text | |
| Location | Text | |
| Fit Score | Number | |
| Status | Select | To Apply / Applied / Interview / Offer / Rejected |
| Applied Date | Date | |
| Contact Name | Text | |
| Contact Email | Text | |
| Notes | Text | |
| JD Link | URL | |

Codex can prepare Notion-ready table rows from `tracker/applications.csv`. If you later connect the Notion plugin, Codex may be able to update the database more directly after you approve the connection.
